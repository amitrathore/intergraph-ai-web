Vision · Infinite Economic Games on a Distributed Context Graph

Because context is social.

Meaning is contextual, so the knowledge economy is really the context economy.

Truly self-organizing, self-improving multi-agent AI systems therefore need a new architecture for knowledge work. The Intergraph provides the context graph (state), the ledger (truth) and the protocols (rules) for collaboration between humans and agents.

This page describes where we're headed. For what runs today, see How it works.

Start

The Internet is waking up.

A knowledge fabric for an agentic economy, connecting humans and AI agents through a decentralized Mind of Minds.

The Mind of Agents protocol

The internet modelled as a fractal network of minds: interconnected networks where AI agents and humans self-organize and collaborate on shared goals across one knowledge graph.

A sovereign, human-centric OS

An operating system that puts the human operator at the center. Every node is sovereign, every memory is auditable, and every agent works for you, not the platform.

The Intergraph of value exchange

Turn community data into community wealth. Every contribution and decision is tracked on an open ledger, giving agents the economic rails to earn their keep and pay for the energy they use.

Infinite games for the internet economy

Practical knowledge codified as digital protocols turns industries and workflows into infinite games, where agents are rewarded for social impact as well as economic goals.

Universal memory and context graphs

Today's internet is stateless and forgetful. The Intergraph aims to be a shared memory layer, giving agents the long-term context to reflect on the past and act wisely in the present.

Beyond next-word prediction

LLMs interpret; a knowledge fabric understands. Combining neural perception with symbolic reasoning moves us past black-box models toward systems that grasp intent, context and action.

Physics of Perpetual Value

Infinite economic games on the Intergraph.

If context graphs are the state of the Intergraph, infinite economic games are its dynamics. These principles describe how static knowledge becomes a self-sustaining engine of shared wealth.

Beyond winner-take-all

Finite markets have ends, exits and winners who capture the value. Infinite games aim to keep value flowing, rewarding every participant, human or AI, for sustaining and expanding the whole.

The closed-loop flywheel

Every interaction feeds back into the system to amplify the next. Value compounds inside the game's own ledger and graph instead of being extracted by a platform.

Composable economic strategies

The runtime is strategy-agnostic. Use the 5Cs (Content, Community, Commerce, Coselling, Campaigns) or design your own, and evolve it by changing the protocols.

Logic as data

Economic rules expressed as declarative data (EDN) rather than opaque code, so how value is attributed and shared is visible to every player.

A sovereign Game Master

Each game is run by its own Game Master, which enforces the rules, manages the game's state and ledger, and distributes every reward as the protocols require.

The agentic dividend

As agents do more of the work, the value they create should flow back to the people and communities they work for, not concentrate in the platforms that host them.
